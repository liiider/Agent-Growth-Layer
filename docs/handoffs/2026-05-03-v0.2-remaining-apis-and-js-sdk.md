# Handoff: V0.2 Remaining APIs and JavaScript SDK

Date: 2026-05-03

## Scope

Completed the remaining V0.2 surface after the experience learning core:

- Feedback API
- Prompt Import API
- Imported skill persistence
- Imported skills entering candidate guidance
- Python SDK `client.experiences.create(...)`
- JavaScript/TypeScript SDK minimum source:
  - `guidance.get()`
  - `experiences.create()`

## Intended Effect

Developers can now:

- Submit task experiences.
- Submit structured feedback against an experience.
- Import existing prompt instructions into a candidate skill.
- Request guidance again and receive both extracted candidate cognition and imported candidate skill guidance.
- Use the minimum JS SDK source to call guidance and experience APIs.

## Implementation Notes

- Feedback is stored in the `feedback` SQLite table.
- Prompt import is deterministic for now:
  - Sentences starting with `Always`, `Check`, `Retrieve`, or `First` become procedure items.
  - Sentences starting with `Never`, `Do not`, or `Don't` become constraints.
- Imported prompt skills are stored as `candidate` skills with `prompt_import_...` evidence refs.
- Guidance assembly reads imported candidate skills from SQLite and merges them with candidate cognitions.
- JS SDK source is present under `sdk/javascript/src`.
