## Intended Effect

Developers can now trace a skill back to cognition evidence, and trace cognition back to experience refs. JavaScript users have the minimum V0.3 SDK surface for guidance, experiences, skills, and exams.

## Implementation Notes

- Audit is currently computed from existing SQLite tables rather than stored as a separate append-only event log.
- `quarantined` skills do not enter guidance because guidance only pulls `verified` skills from the skill table and candidate cognitions/imported skills from their own stores.
- JS SDK still needs TypeScript build validation once `typescript` is installed.
